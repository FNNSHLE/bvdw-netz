# ADR-005: Das Netz ist eine Sicht, nicht der Kern

Status: vorgeschlagen, 27.10.2026

## Kontext
Das Netzdiagramm ist der Aha-Moment im Pitch. Im Alltag braucht Membership Services Suche, Steckbrief und Listen.

## Entscheidung
Der Kern ist die Aggregat-Tabelle Firma mal Format mal Zeit und vier Kennzahlen je Firma. Das Netz ist eine Oberfläche darüber, Phase 2, und zeigt, was man nicht gesucht hat. Es wird nie zur einzigen Zugriffsform.

## Folgen
Phase 1 liefert Wert ohne eine Zeile Oberfläche. Das Netz kann später wachsen oder wegfallen, ohne dass Daten verloren gehen.
